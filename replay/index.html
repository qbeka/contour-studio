Why you can trust this

  • Same numbersOnce the preview settles, the canvas and the SVG read one shared geometry. There is no separate preview to drift away from the file.
  • Proved errorEach path carries a bound for simplifying and rounding. On the quiet ridge the bound is 0.22 units, and the sampled distance is 0.19 units.
  • Lines stay apart0 crossings and 0 lost paths across 9 size table rows and 420 random scenes. A path that fails a topology rule is retried at finer settings.
  • Repeatable filesOne workflow's scene gave identical bytes in Chromium, Firefox, WebKit and Node. Chromium, Firefox, WebKit and resvg drew three scenes within 1 px.
  • Tests that can fail178 unit tests and 41 browser tests. 69 of 70 seeded bugs were caught by a named test, and the last one timed out.
  • The worker's real jobIt made drafts slower, 17 ms against 10 ms. It stays because it cut the largest frame gap on a heavy scene from 204 ms to 25 ms.

What this does not show

  • All timings come from one fast laptop with other work running on it.
  • Nobody outside this project has used it yet.
  • Path editing was checked in paper.js, not in a desktop vector editor.
  • Grid error is not part of the export bound. It reaches about 0.79 units on the quiet ridge.
  • Exports are polylines, so smooth lines need many nodes.

This page runs on the main thread and uses Contour's own field, contour, simplify and SVG code. The studio does the same work in a worker.
