Details

Contour is a design tool for original line artwork. You place peaks and ridges on a sheet, drag them, and the lines follow. Export SVG gives you the drawing you see above, and every line stays its own path.

The studio is the same drawing engine with the rest of the tools: more sources, ridges, line styling, and React and PNG export.

Limits

  • All timings come from one fast laptop.
  • Grid error is not part of the proved bound and reaches about 0.79 units on the quiet ridge.
  • Exports are polylines, so smooth lines need many nodes.
  • I checked path editing in paper.js but have not tested Figma, Illustrator or Inkscape.
  • Nobody outside this project has used it yet.
