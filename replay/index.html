Details

Contour is a design tool for original line artwork. You place peaks and ridges on a sheet, drag them, and the lines follow. Every plate above is a live drawing, and the tint under the lines is built from the same paths, so it moves with them.

Export gives you the drawing as an SVG where every line stays its own path, or as a wallpaper or poster drawn from the same field at a new shape. The address of this page always holds the drawing you see, so a link brings it back.

The studio is the same drawing engine with the rest of the tools: ridges you draw yourself, exact numbers, scene files, and React export.

Limits

  • All timings come from one fast laptop.
  • The numbers above were measured on plain lines, and the plates here are drawn at this stage's frame with tint, so the export panel reports each file's own size.
  • Grid error is not part of the proved bound and reaches about 0.79 units on the quiet ridge.
  • Exports are polylines, so smooth lines need many nodes, and tint repeats each line as a filled shape.
  • I checked path editing in paper.js but have not tested Figma, Illustrator or Inkscape.
  • Nobody outside this project has used it yet.
